# 스터디아 왕국 초등 · 설치 안내

초등 1~6학년 공부 RPG. 루틴런 초등의 과목 체크·점수표 위에 보스전·왕국·레이드를 얹었어요.
화면은 **GitHub Pages**, 로그인·기록은 **구글 시트 + Apps Script**가 맡아요.

```
아이 폰 ──(화면)── GitHub Pages   index.html · admin.html · rank.html · support/
   │
   └──(로그인·기록)── Apps Script 웹 앱 ── 구글 시트 [계정] [기록] [승인] [조정] [오류]
```

| 파일 | 하는 일 |
|---|---|
| `index.html` | 학생 앱 (보호자 링크로 열면 보호자 리포트) |
| `admin.html` | 선생님 화면: 계정, 숙제검사 확인, 점수 조정, 마음 신호 |
| `rank.html` | 반 랭킹 사이트: 캐릭터 레이스, 권역 대항전, 보스·레이드 현황 |
| `game-data.js` | 왕국·보스·레이드·점수표·캐릭터 그림. 숫자를 바꿀 땐 여기 |
| `config.js` | Apps Script 웹 앱 주소 (`API_URL`) |
| `support/` | 지원센터 (학생·보호자·선생님 안내, 규칙 도감, FAQ) |
| `apps-script/` | 구글 시트 Apps Script에 붙여 넣는 서버 코드 |

---

## 1단계. 구글 시트와 Apps Script (약 10분)

1. 구글 드라이브에서 새 스프레드시트를 만들고 이름을 `스터디아 서버`로 정해요.
2. 메뉴 **확장 프로그램 > Apps Script**.
3. 왼쪽 `Code.gs` 내용을 모두 지우고 `apps-script/Code.gs`를 통째로 붙여 넣고 저장(Ctrl+S).
4. 톱니바퀴 **프로젝트 설정**에서 시간대를 **(GMT+09:00) 서울**로 바꿔요.
5. 시트로 돌아가 새로 고침하면 위쪽에 **스터디아** 메뉴가 생겨요.
6. **스터디아 > 1. 처음 설정**을 눌러요.
   - 권한 창: 내 계정 선택 → "고급" → "(안전하지 않은 페이지)로 이동" → 허용. 내가 만든 스크립트라 괜찮아요.
   - 선생님 아이디(예: `teacher`)와 비밀번호(8자 이상)를 넣으면 탭 5개가 생겨요.

## 2단계. 웹 앱으로 배포 (약 3분)

1. Apps Script 오른쪽 위 **배포 > 새 배포** → 유형 **웹 앱**.
2. **실행: 나** / **액세스 권한: 모든 사용자** → **배포**.
3. 나온 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.

> "모든 사용자"여도 아이디·비밀번호나 보호자 링크 없이는 아무 기록도 볼 수 없어요.

## 3단계. 주소 넣기와 GitHub Pages (약 3분)

1. 이 저장소에서 `config.js` → 연필(✏️) → `API_URL: ''` 따옴표 안에 웹 앱 URL 붙여 넣기 → Commit.
2. **Settings > Pages**에서 Branch **main / (root)** → Save. (이미 켜져 있으면 건너뛰어요.)
3. 1~2분 뒤 주소:
   - 학생: https://youlifeme86-spec.github.io/studia-kids/
   - 선생님: https://youlifeme86-spec.github.io/studia-kids/admin.html
   - 랭킹: https://youlifeme86-spec.github.io/studia-kids/rank.html
   - 지원센터: https://youlifeme86-spec.github.io/studia-kids/support/

## 4단계. 보호자 동의 → 계정 나눠 주기

1. 만 14세 미만이라 **보호자 동의를 먼저** 받아요. 동의 항목과 예시 문장은 `support/parent.html`에 있어요.
2. `admin.html`에 선생님 아이디로 로그인 → **계정 만들기**. 동의일을 넣어야 만들어져요. 여러 명은 `아이디, 이름, 메모`를 줄마다 붙여 넣어요.
3. **안내문 복사**로 아이·보호자에게 보내고, **학생 계정 > 보호자 링크**를 보호자께 보내요.

## 매일 쓰는 법 (선생님)

- **오늘**: 미션1 숙제검사 확인(5점 + 7일 마스터의 가호), 마음 신호, 학생별 점수·마음 칸.
- **점수 조정**: 늦게 알린 체크(그날~다음 날), 추가 포인트 1~30, 거짓 체크 감점 1~5. 아이가 앱을 다시 열면 랭킹에 반영돼요.
- **학생 계정**: 비밀번호 새로 발급, 멈추기, 보호자 링크, 동의일 고치기.
- **오류 기록**: 아이 폰에서 난 오류와 신고.

## 규칙 한눈에

하루 랭킹 상한 30점 · 한 달 기준 300점 · 체크 마감 밤 12시 · 1점 = 10 데미지.
수학·영어 5점(주 6), 국어·EBS 3점(주 4), 미션1 5점(주 2, 선생님 확인), 미션2·책읽기·청소 1점, 학교숙제 1점(주 1).
자세한 표는 `support/rules.html`.

## 고치거나 업데이트할 때

- **화면**: 파일을 바꾼 뒤 `./bump-version.sh "바꾼 내용"`을 실행하고 같이 커밋해요. version.json, 앱 버전, 모든 페이지의 css/js 주소 뒤 `?v=` 값이 한 번에 바뀌어서 브라우저가 옛 파일을 쓰지 않고, 열려 있는 앱에는 "새 버전" 버튼이 떠요.
- **점수표**: `game-data.js`의 `ACT`와 `apps-script/Code.gs`의 `ACT`를 같이 바꿔요.
- **서버(Code.gs)**: 저장 후 **배포 > 배포 관리 > 연필 > 버전: 새 버전 > 배포**. "새 배포"를 누르면 URL이 바뀌니 주의.

## 보안 메모

- 비밀번호는 솔트 + SHA-256 해시로만 저장돼요. 잊으면 새로 발급해요.
- 같은 아이디로 8번 틀리면 10분 잠겨요. 로그인은 60일 유지돼요.
- 랭킹에는 캐릭터 이름·동물만 나가요. 실명은 선생님 화면에만 있어요.
- 보호자 링크가 새어 나가면 [계정] 탭 보호자코드 칸을 다른 10자리 영문·숫자로 바꾸면 예전 링크가 막혀요.
- 같은 github.io 주소의 다른 앱과 섞이지 않게 브라우저 저장 키는 `sk-`로 시작해요.
